源码地址：ym7k.com/19311/

这套是基于 PbootCMS 开发的人力资源、劳务公司企业官网模板，主打人力外包、劳务派遣、猎头招聘、企业用工咨询，适合人力资源公司、劳务中介、猎头机构搭建品牌展示官网，后台简单易上手，全端自适应。

### ✅ 页面模块

- **首页大屏轮播**：品牌标语、企业宣传 banner，商务大气风格
- **选择我们**：优势板块，展示服务亮点、核心竞争力
- **服务范围**：劳务派遣、人力外包、企业招聘、用工咨询等业务介绍
- **成功案例**：合作企业、服务项目案例展示
- **关于我们**：公司简介、发展历程、团队介绍
- **新闻资讯**：行业动态、招聘资讯、企业新闻发布
- **联系我们**：联系方式、电话、地址、在线留言

### ✅ 功能特性

- ✔ 响应式自适应：PC、平板、手机自动适配，一套模板多端展示
- ✔ PbootCMS 内核：轻量化、开源易维护，后台可视化管理
- ✔ 栏目自定义：可自由增删栏目，改成猎头、外包、工厂招工、校企合作等业务
- ✔ 留言表单：客户在线提交咨询，后台接收线索
- ✔ 图片轮播、案例图集、新闻分页、基础 SEO 配置
- ✔ 后台可改 logo、轮播图、文字、联系方式，不需要复杂代码
